CSS Units

UnitTypeMeaning
pxAbsoluteOne CSS pixel
cm, mm, inAbsolutePhysical measures
pt, pcAbsolute1/72 inch, 12 points
emRelativeFont size of the element
remRelativeFont size of the root
%RelativeShare of the parent
vw, vhViewport1% of viewport width or height
vmin, vmaxViewport1% of the smaller or larger side
chRelativeWidth of the 0 glyph
