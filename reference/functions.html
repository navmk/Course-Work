CSS Functions Reference

Functions compute values inside property declarations.

FunctionDescriptionExample
calc()Math with mixed unitswidth: calc(100% - 2rem)
var()Reads a custom propertycolor: var(--ink)
min() / max()Smallest or largest valuewidth: min(90%, 60rem)
clamp()Value held between limitsfont-size: clamp(1rem, 2vw, 2rem)
rgb() / hsl()Color valueshsl(220 80% 50%)
linear-gradient()Gradient imagelinear-gradient(red, blue)
url()Points to a fileurl(bg.png)
repeat() / minmax()Grid track sizingrepeat(3, minmax(0, 1fr))
attr()Reads an HTML attributecontent: attr(title)
