Client/Server

Client: A client is a computer or program that requests services or resources from a server.

Server: A server is a computer or program that provides services or resources to clients.

Components of Web Application

View Layer: The part of the application that the user sees and interacts with.

Business Layer: Handles the logic and processing of data.

Data Access Layer: Manages communication with the database.

Types of Web Content

  • Text
  • Images
  • Audio
  • Video
  • Animation

HTTP and HTTP Request

HTTP: HTTP stands for HyperText Transfer Protocol. It is used to transfer data over the web.

HTTP Request and Response: The client sends a request to the server, and the server sends back a response.

Working of HTTP Communication: The browser sends a request, the server processes it, and then returns the requested webpage.

Dynamic Web Pages

Definition: Web pages that change content based on user actions or data.

Characteristics: Interactive, updated in real time, often connected to a database.

Examples: Social media sites, online shopping sites, email websites.

Application Servers

Definition: A server that runs applications and delivers them to client devices.

Purpose: To host and run the business logic of web applications.

Major Services: Security, database connection, and transaction management.

Web Security

Definition: Protecting websites and web applications from online threats.

Importance: Prevents data theft, hacking, and misuse of information.

Basic Security Measures: Strong passwords, HTTPS, firewalls, and regular updates.
